# BOTC Aid — статистика

Страница: https://ultimatum424.github.io/botc-aid/. HTML/CSS/JS без сборки и зависимостей.

## Автоматическое обновление

Явная отправка игры из Android сохраняет закрытый оригинал в Firebase и создаёт фоновое задание. Сервер проверяет данные, готовит публичную модель и одним коммитом обновляет `data/dataset.json` и `data/version.json`. Pages публикует main/(root). Статус «Опубликована» появляется после проверки точных данных на сайте. Архивирование игр и явная синхронизация игроков также обновляют сайт. Локальные черновики при возвращении сети не отправляются.

Временные ошибки повторяются с ограничением попыток. После ошибки доступа к GitHub админ может заменить ключ и нажать «Повторить публикацию сайта». Ключ находится в закрытом Secret Manager, вне репозитория, браузера и APK.

Открытая страница проверяет небольшой файл версии раз в минуту и при возвращении на вкладку. Новый JSON проверяется по SHA-256. При сбое остаётся предыдущая отображаемая версия. Посетителям не нужны аккаунты или подключение к Firebase.

## Публичные данные

`dataset.json`: `{schemaVersion:1,isTest,datasetId,generatedAt,publicationRevision?,players,games}`. Профиль содержит только `publicId,name`.

Игра: `gameId,isTest,caseNumber,title,script,date,winner`, исходные счётчики, `fabled,demonBluffs,participants,snapshots`. Номер проверки может быть null. Итоговый участник содержит publicId или null для гостя, имя профиля и игровой ник, роль при раздаче, итоговую роль и команду, состояние жизни и голос мёртвого.

Исторические жетоны: `order,player_name,role_id,related_role_id?,alignment,is_dead,used_ghost_vote,reminders[{role_id,reminder}]`. Историческим страницам publicId не приписывается: ClockTracker не даёт неизменяемых ID участников для каждой страницы. Гости не объединяются по совпадению имён.

`version.json`: `{schemaVersion:1,revision,sha256,generatedAt,gameCount}` — небольшой указатель на целостный снимок. Оба файла записываются в одном коммите.

Преобразователь использует список разрешённых полей. NFC/internalId, sitePlayerId, email администраторов, закрытые пути, учётные данные, неизвестные расширения и приватные конверты не включаются.

## Как читать статистику

Тестовые и реальные игры показываются отдельно. Если есть реальные партии, по умолчанию открываются они. Начальные 10 игр являются синтетическими Android-проверками с назначенными победителями.

Личный процент побед не считается: правило для сменившего команду игрока ещё не выбрано. Номера страниц не обозначают точный день/ночь. Экспорт не содержит полного журнала номинаций, голосов, причин смерти и времени действий. Напоминания являются отметками рассказчика. Traveller уже входит в число участников исходных тестовых выгрузок.

## Разработка

Локальный просмотр: `python3 -m http.server 8765`. Серверная очередь, преобразователь, проверки и подробная документация находятся в основном Android/Firebase-проекте. Здесь публикуются только сайт и разрешённые данные. Серверу достаточно Contents: Read and write для одного репозитория botc-aid.
