# BOTC Aid — тестовая статистика

Простая статическая страница для GitHub Pages. Данные: 10 синтетических Android-проверок, сохранённых в Firebase, 37 страниц ClockTracker, 6 профилей.

## Публикация

В GitHub: Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
Адрес: https://ultimatum424.github.io/botc-aid/

Сайт не требует сборки, библиотек, входа пользователей или подключения браузера к Firebase. Для локального просмотра: `python3 -m http.server 8765`, затем http://localhost:8765.

## Данные

`data/dataset.json` — единственный файл данных. `schemaVersion: 1`, `isTest: true`, `datasetId`, `generatedAt`, `players`, `games`.

Профиль: `publicId`, `name`. Игра: `gameId`, `caseNumber`, `title`, `script`, `date`, `winner`, экспортированные счётчики, `fabled`, `demonBluffs`, итоговые `participants` и `snapshots`. Итоговый участник содержит `publicId` или `null` для гостя, имя профиля и игровой ник, роль при раздаче, итоговую роль и команду, состояние жизни и использование голоса мёртвого. Напоминания на страницах содержат только `role_id` и `reminder`.

Исторические жетоны не получают `publicId`: ClockTracker не даёт неизменяемые ID участников на каждой странице. Нельзя уверенно связывать их по позиции или совпадению ника. Статистика профиля считается по итоговому составу. Гости никогда не объединяются по имени.

Победители назначались для тестов. Личный процент побед не рассчитывается. Номера страниц не обозначают точный день/ночь. Экспорт не содержит полного журнала номинаций, голосов, причин смерти или времени действий. Напоминания — сохранённые отметки рассказчика. Traveller уже входит в число участников этих выгрузок.

## Обновление и доступ

Этот первый выпуск — явная выгрузка из Firebase и публикация в GitHub. Автоматическая отправка новых игр из Android на Pages ещё не подключена. Исходники ClockTracker, NFC/internalId, sitePlayerId, email, закрытые пути и учётные данные сюда не включаются.

Преобразователь и команда выгрузки находятся в закрытой локальной рабочей папке проекта: `backend/public-stats.mjs`, `backend/export-public-stats.mjs`. Они проверяют исходники и формируют публичные данные по списку разрешённых полей. Страница использует только относительные ссылки и вставляет текст через `textContent`.

GitHub App ограничивается только репозиторием `ultimatum424/botc-aid`. Для этого выпуска в репозиторий загружается только содержимое папки сайта.
